Deakrix Riftbound Tracker

A free Windows app for the Riftbound TCG, made by Stefan.

Keep your Riftbound collection, decks and card prices in one place. Everything stays on your PC: no account, no server, no ads.

Download for Windows Source on GitHub

Features

  • Collection by set with normal and foil counts, set progress per rarity and missing lists
  • Full card catalogue with filters, rules text, errata and ban badges
  • Deck builder with deck limits, ownership check and Cardmarket wants list export
  • Daily Cardmarket prices, collection value and value history
  • Wishlist with price alerts, sales cart and sold log with profit
  • Borrowed and lent cards, local stores and events, official dates and rules
  • Legend matchups with counter cards, and a booster opening simulator
  • German and English interface, automatic updates
